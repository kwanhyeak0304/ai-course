# 단위 변환기 스펙 문서 (SPEC.md)

## 1. 기술 및 파일 구성

### 기술
- Python 3.10 이상
- Flet 1.0 (외부 라이브러리 추가 설치 없이 Flet 1.0 및 Python 표준 라이브러리만 사용)
- Flet 1.0 공식 뼈대 문법만 준수 (`ft.run`, `ft.Button(content=...)`, `ft.Colors` 등)

### 파일 구성
- `SPEC.md`: 프로그램 스펙 및 동작 규칙 문서
- `logic.py`: 단위 변환 및 유효성 검사 로직 (Flet 미참조 순수 파이썬 모듈)
- `main.py`: Flet 1.0 기반 단일 창 GUI 화면 구성 및 이벤트 처리
- `test_logic.py`: `logic.py`의 단위 변환 및 에러 처리를 검증하는 자동화 테스트 스크립트

## 2. 동작 규칙

### 지원 단위
- **길이**: `mm`, `cm`, `m`, `km`
- **온도**: `°C`, `°F`
- 두 드롭다운(출발 단위, 도착 단위) 모두 6개 단위를 기본 제공한다.

### 입력값 검증 및 에러 처리
1. **빈 입력**: 입력값이 비어있거나 공백만 있는 경우
   - 에러 반환: `"값을 입력해 주세요"`
   - 변환 결과는 빈 문자열(`""`)로 설정
2. **숫자가 아닌 입력**: 숫자로 변환할 수 없는 문자열인 경우
   - 에러 반환: `"숫자만 입력할 수 있습니다"`
   - 변환 결과는 빈 문자열(`""`)로 설정
3. **이종 단위 변환 (길이 ↔ 온도)**:
   - 에러 반환: `"길이와 온도는 서로 변환할 수 없습니다"`
   - 변환 결과는 빈 문자열(`""`)로 설정
4. **정상 입력**:
   - 에러 없음 (`None` 또는 빈 문자열)
   - 계산된 변환 결과를 문자열로 반환

### 계산 공식
- **동일 단위**: `val` 그대로 반환
- **길이 변환 (기준: m)**:
  - 1 mm = 0.001 m
  - 1 cm = 0.01 m
  - 1 m = 1 m
  - 1 km = 1000 m
  - 공식: `val * factor(from) / factor(to)`
- **온도 변환**:
  - `°C` → `°F`: `val * 9 / 5 + 32`
  - `°F` → `°C`: `(val - 32) * 5 / 9`
- **숫자 서식**:
  - 부동소수점 오차 방지를 위해 최대 소수점 6자리까지 반올림
  - 정수로 나누어떨어지는 경우 불필요한 `.0`은 제거하여 정수 형태로 표시 (예: 100 cm → 1 m)

### 추가 기능 (5단계)
- **변환 이력 저장 및 삭제**:
  - 변환 성공 시 "입력값 출발단위 = 결과값 도착단위" 형태로 기록 목록에 추가
  - 각 이력 우측의 "삭제" 버튼 클릭 시 해당 항목 개별 삭제
- **단위 맞바꾸기(스왑)**:
  - 출발 단위와 도착 단위를 상호 교환하는 편의 기능

## 3. 화면 구성

- 창 크기: 가로 360px, 세로 440px, 크기 조절 불가 (`resizable = False`)
- 상단 행: 값 입력 필드(`TextField`, width=150) + 출발 단위 드롭다운(`Dropdown`, width=120)
- 중간 행: 아래 화살표 안내 텍스트("↓") + 단위 맞바꾸기 버튼(`Button`, content="단위 맞바꾸기 ⇄")
- 결과 행: 결과 표시 텍스트/필드(`TextField` 읽기모드 또는 텍스트) + 도착 단위 드롭다운(`Dropdown`, width=120)
- 실행 버튼: "변환" 버튼 (`Button`, expand=True, bgcolor=ft.Colors.BLUE, color=ft.Colors.WHITE)
- 안내 문구: 에러 메시지 표시용 빨간색 텍스트 (`Text`, color=ft.Colors.RED)
- 하단 목록: 변환 이력 목록 (`ListView`, expand=True, spacing=4) 및 각 줄 삭제 버튼
