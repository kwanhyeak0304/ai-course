# 주차 요금 계산기 스펙 문서

## 1. 개요
본 프로그램은 차량의 입차 및 출차 시각을 입력받아 주차 요금을 계산하고, 주차 기록을 관리하는 프로그램입니다.

## 2. 동작 규칙

### 2.1 시간 입력 및 처리
- **형식**: `HH:MM` (24시간제) 형식을 사용합니다. (예: `09:30`, `23:15`)
- **유연성**: `9:30`과 같이 한 자리 시각을 입력해도 `09:30`으로 자동 보정하여 인식합니다.
- **자정 처리**: 출차 시각이 입차 시각보다 이전인 경우(예: 입차 23:00, 출차 01:00), 차량이 자정을 넘어 다음 날 출차한 것으로 간주하여 주차 시간을 계산합니다.
- **오류 처리**: 잘못된 시간 형식(예: `25:00`, `abc`) 입력 시 사용자에게 에러 메시지를 표시합니다.

### 2.2 요금 계산 규칙
- **무료 구간**: 주차 시간 **30분까지는 무료(0원)**입니다.
- **유료 구간**: 30분을 초과한 시점부터 **10분마다 500원**이 부과됩니다.
- **단위 계산**: 10분 미만의 잔여 시간은 10분으로 간주하여 올림 계산합니다. (예: 31분 주차 시 10분 단위 1회 적용 $\rightarrow$ 500원)
- **최대 요금**: 1회 주차당 최대 요금은 **20,000원**으로 제한합니다.

### 2.3 기록 관리
- 계산된 기록은 목록에 추가되며 `[입차 시각, 출차 시각, 주차 시간, 요금]` 정보를 가집니다.
- 요금은 천 단위마다 쉼표(`,`)를 포함하여 표시합니다.
- 목록에서 특정 항목을 선택하여 삭제할 수 있으며, 삭제 시 전체 요금 합계가 실시간으로 재계산됩니다.

| 테스트 구분 | 입차 시각 | 출차 시각 | 주차 시간 | 기대 요금 | 비고 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 무료 구간 | 09:00 | 09:30 | 30분 | 0원 | 30분 정각 무료 |
| 유료 시작 | 09:00 | 09:31 | 31분 | 500원 | 30분 초과 시 10분 1회 |
| 유료 단위 | 09:00 | 09:40 | 40분 | 500원 | 40분까지는 1회 적용 |
| 유료 올림 | 09:00 | 09:41 | 41분 | 1,000원 | 41분은 2회 적용 |
| 자정 경과 | 23:00 | 01:00 | 2시간 | 10,000원 | 다음 날로 계산 |
| 최대 요금 | 09:00 | 15:00 | 6시간 | 20,000원 | 계산값(27,500원) < 최대값 |
| 최대 요금 제한 | 09:00 | 20:00 | 11시간 | 20,000원 | 계산값(32,500원) > 최대값 적용 |
| 잘못된 형식 | 25:00 | 26:00 | - | 에러 발생 | 시간 범위 초과 |
| 빈 입력 | (공백) | 10:00 | - | 에러 발생 | 필수 입력 누락 |
