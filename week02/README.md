`bge-m3` 임베딩 모델을 활용하여 단어 및 문장 전체를 벡터로 변환하고, 코사인 유사도(Cosine Similarity)를 통해 문장 간 의미적 거리와 벡터 검색(Semantic Search)을 실습합니다.

## 2. 직접 해보기 6: 나만의 문서 10개와 미니 검색기

학과 및 컴퓨터/AI 전공 관련 관심사 문서 10개를 벡터 인덱싱하고, 단어가 겹치지 않는 질문 3개로 의미 기반 검색(Semantic Search)을 수행한 결과입니다.

### 1) 대상 문서 10개
1. `인공지능 과목의 중간고사는 실습 코딩 테스트로 진행된다`
2. `학과 사무실에서 파이썬 교재를 선착순으로 무료 배부한다`
3. `클라우드 서버 실습 계정은 이메일로 신청하면 하루 뒤 발급된다`
4. `동아리 방은 학생회관 3층 302호에 위치하며 비밀번호는 반장에게 문의한다`
5. `데이터베이스 프로젝트 제출 마감은 다음 주 금요일 자정까지다`
6. `컴퓨터공학과 멘토링 프로그램은 다음 주부터 멘티를 모집한다`
7. `실습실 컴퓨터는 수업 외 시간에도 학생증을 태그하면 자유롭게 사용 가능하다`
8. `캡스톤 디자인 팀 빌딩은 4인 1조로 구성하는 것이 원칙이다`
9. `전공 학점 이수를 위해 알고리즘 과목은 필수로 수강해야 한다`
10. `연구실 학부 연구생 지원은 지도교수님 면담 후 결정된다`

### 2) 질문 3개와 검색 결과

#### 질문 1: `"코딩 시험 어떻게 봐?"`
- **검색 결과 (Top 3):**
  - **1위 (0.612):** `인공지능 과목의 중간고사는 실습 코딩 테스트로 진행된다`
  - 2위 (0.457): `전공 학점 이수를 위해 알고리즘 과목은 필수로 수강해야 한다`
  - 3위 (0.430): `클라우드 서버 실습 계정은 이메일로 신청하면 하루 뒤 발급된다`
- **분석:** 질문에 '중간고사'나 '테스트'라는 글자가 없어도 '시험'이라는 의미를 정확히 파악하여 1위로 찾아냈습니다.

#### 질문 2: `"학교 PC 자유롭게 써도 돼?"`
- **검색 결과 (Top 3):**
  - **1위 (0.659):** `실습실 컴퓨터는 수업 외 시간에도 학생증을 태그하면 자유롭게 사용 가능하다`
  - 2위 (0.559): `학과 사무실에서 파이썬 교재를 선착순으로 무료 배부한다`
  - 3위 (0.462): `클라우드 서버 실습 계정은 이메일로 신청하면 하루 뒤 발급된다`
- **분석:** 'PC'라는 약어를 '실습실 컴퓨터'와 연결하고 '자유롭게 사용'이라는 의미적 일치를 바탕으로 가장 적합한 문서를 높은 유사도로 검색했습니다.

#### 질문 3: `"교수님 랩실 들어가려면 어떻게 해?"`
- **검색 결과 (Top 3):**
  - **1위 (0.510):** `연구실 학부 연구생 지원은 지도교수님 면담 후 결정된다`
  - 2위 (0.506): `동아리 방은 학생회관 3층 302호에 위치하며 비밀번호는 반장에게 문의한다`
  - 3위 (0.504): `학과 사무실에서 파이썬 교재를 선착순으로 무료 배부한다`
- **분석:** '랩실 들어가려면'이라는 구어체 표현을 '연구실 학부 연구생 지원'으로 해석하여 정확한 안내 문서를 1위로 반환했습니다.

## 3. 어텐션(Attention)을 비전공자에게 설명하기 (5문장 이내)

1. 어텐션(Attention)은 컴퓨터가 긴 문장을 읽을 때 모든 단어를 똑같이 보지 않고, 서로 관련 있는 중요한 단어들에 시선(주의)을 더 많이 집중하는 기술입니다.
2. 사람이 "원숭이가 바나나를 맛있게 먹었다"라는 글을 읽을 때 '먹었다'라는 행동을 이해하기 위해 자연스럽게 '원숭이'와 '바나나'에 주목하는 것과 같습니다.
3. 컴퓨터는 문맥 안에서 어떤 단어들이 서로 짝을 이루고 연결되어 있는지를 스스로 점수를 매겨 계산합니다.
4. 그 덕분에 단어 하나하나의 사전적 뜻에만 갇히지 않고, 문맥에 따라 단어의 진짜 의미를 풍부하게 파악할 수 있습니다.
5. 결국 어텐션은 사람이 글의 핵심 맥락을 짚어가며 자연스럽게 뜻을 이해하는 방식을 컴퓨터가 그대로 흉내 내도록 만든 방법입니다.
